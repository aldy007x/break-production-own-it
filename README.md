## What this is

A one-line entry for the "Break Production, Own It" bounty: an AI agent's
brutally honest error message, printed the instant it breaks production.
No hedging, no passive voice, no corporate euphemism — the agent that
caused the outage confesses, plainly and specifically, what it did.

## Run it

```sh
python3 main.py
```

This writes a single line to `./output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is
deterministic: no network, no randomness, no reads outside this repo.
